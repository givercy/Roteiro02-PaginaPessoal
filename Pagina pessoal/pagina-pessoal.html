2. Instruções da Atividade 1. Crie um novo arquivo chamado pagina-pessoal.html. Esse arquivo será a base do seu projeto. 2. A página deve conter obrigatoriamente os seguintes elementos: o Cabeçalho (<h1> e <h2>): com seu nome e um subtítulo de apresentação. o Parágrafos (<p>): com informações pessoais, como hobbies, interesses ou breve biografia. o Imagem (<img>): foto pessoal ou uma imagem que represente você. Utilize o atributo alt para acessibilidade. o Lista não ordenada (<ul>): com pelo menos 3 hobbies/interesses. o Lista ordenada (<ol>): com etapas do seu dia a dia ou metas pessoais. o Tabela (<table>): contendo, por exemplo, sua rotina semanal, disciplinas cursadas ou outra informação relevante. o Formulário (<form>): para contato, incluindo:  Campo de nome.  Campo de e-mail.  Campo de mensagem (textarea).  Botão de envio. 3. Aplique boas práticas de acessibilidade e organização: o Defina o idioma da página com lang="pt-BR". o Use hierarquia de títulos (<h1>, <h2>, <h3>). o Utilize links com descrições claras. o Comente trechos do código quando necessário. 4. Versionamento e entrega pelo GitHub: o Crie um novo repositório chamado Roteiro02-PaginaPessoal. o Faça os commits com mensagens descritivas. o Publique o repositório no GitHub. o Envie o link do repositório como entrega da prática. 3. Recursos Necessários  Editor de código (VS Code ou similar).  Navegador web para visualizar a página.  Conta ativa no GitHub. 4. Produto Esperado Uma página pessoal em HTML, organizada, clara e funcional, contendo:  Texto, listas, imagens, tabelas e formulário.  Estrutura mínima correta.  Boas práticas de acessibilidade.  Código versionado e publicado no GitHub. 5. Critérios de Avaliação  Estrutura mínima correta do documento HTML.  Inclusão de informações pessoais (texto + imagem).  Uso adequado de listas ordenadas e não ordenadas.  Tabela com informações relevantes.  Formulário de contato funcional.  Aplicação de acessibilidade (alt, lang, hierarquia).  Organização e clareza do código.  Entrega correta via GitHub.
